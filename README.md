
# BookPreOrder

## Описание проекта

BookPreOrder — это веб-приложение для интернет-магазина книг с системой предварительного заказа (предзаказа).

Пользователи могут просматривать каталог книг, оформлять обычные заказы и бронировать книги, которые ещё не поступили в продажу.

## Основные возможности

- Регистрация и авторизация пользователей.
- Просмотр и поиск книг.
- Просмотр категорий книг.
- Оформление обычных заказов.
- Оформление предзаказов на книги.
- Отслеживание статуса заказов и предзаказов.
- Управление заказами для менеджеров.
- Управление книгами, категориями и пользователями для администратора.
- Автоматическое обновление статуса предзаказа после даты выхода книги.
- История изменения статусов заказов.

## Роли пользователей

- USER — просмотр каталога и оформление заказов.
- MANAGER — управление заказами и предзаказами.
- ADMIN — управление книгами, категориями и пользователями.

## Технологии

- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- PostgreSQL
- Maven
- JWT
- REST API
- Swagger / OpenAPI
- Lombok

## Запуск проекта

1. Установить Java 21 и PostgreSQL.
2. Создать базу данных `book_preorder`.
3. Настроить подключение к базе данных в `application.properties`.
4. Запустить приложение через IntelliJ IDEA или Maven.

Документация API Swagger:

http://localhost:8080/swagger-ui/index.html
